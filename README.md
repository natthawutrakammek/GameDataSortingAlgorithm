## 💡 กลไกการเรียนรู้อัลกอริทึมในเกม

### 1. 🫧 Bubble Sort (การเรียงลำดับแบบฟองสบู่)
* **กลไกในเกม**:
  * เกมจะชี้คู่ข้อมูลที่อยู่ติดกัน `[j]` และ `[j+1]`
  * ผู้เล่นต้องสังเกตค่า:
    * หากตัวซ้ายมากกว่าตัวขวา ให้กด **"สลับตำแหน่ง (SWAP)"**
    * หากตัวซ้ายน้อยกว่าหรือเท่ากับตัวขวา ให้กด **"ข้าม / คงเดิม (KEEP)"**
  * เมื่อตรวจจนสุดรอบ ค่าที่มากที่สุดจะถูก "ดัน" ไปอยู่ทางขวาสุด และตำแหน่งนั้นจะถูกล็อค (Locked/Sorted ✨)
* **สิ่งที่ได้เรียนรู้**:
  * เข้าใจการทำงานแบบ Pairwise Comparison
  * สังเกตกรณี Worst-case ที่ต้องสลับบ่อยมาก ($O(n^2)$)
  * สังเกตกรณี Best-case ที่ข้อมูลเรียงอยู่แล้วจะผ่านได้ในรอบเดียว ($O(n)$)

### 2. 🎯 Selection Sort (การเรียงลำดับแบบเลือก)
* **กลไกในเกม**:
  * เกมจะกำหนดตำแหน่งเป้าหมาย `[i]` ทางด้านซ้าย
  * ผู้เล่นต้องสแกนดูส่วนที่ยังไม่จัดเรียง `[i .. n-1]` แล้ว **คลิกเลือกไอเทมที่มีค่าน้อยที่สุด (Minimum Value)**
  * เมื่อเลือกถูกต้อง ไอเทมนั้นจะถูกสลับมาวางที่ตำแหน่ง `[i]` แล้วล็อคทันที
* **สิ่งที่ได้เรียนรู้**:
  * เข้าใจกลยุทธ์การค้นหาค่าน้อยสุดทีละรอบ
  * สังเกตว่าจำนวนการสลับ (Swaps) มีน้อยมาก ไม่เกิน $n-1$ ครั้งเสมอ จึงประหยัดการเขียนข้อมูล เหมาะกับหน่วยความจำที่มีต้นทุนการเขียนสูง

### 3. 📥 Insertion Sort (การเรียงลำดับแบบแทรก)
* **กลไกในเกม**:
  * เกมจะกำหนดให้การ์ดตัวแรกเป็นส่วนที่เรียงแล้ว (Sorted Subarray)
  * ในแต่ละรอบ จะหยิบการ์ดตัวถัดไปมาเป็น **Key** (ไฮไลท์สีม่วง)
  * เปรียบเทียบ Key กับตัวเลขที่อยู่ทางซ้าย:
    * หาก Key น้อยกว่าตัวซ้าย ให้กด **"เลื่อนซ้าย (SHIFT LEFT)"**
    * หาก Key มากกว่าหรือเท่ากับตัวซ้าย (หรือเลื่อนมาถึงหน้าสุด) ให้กด **"วางลง (INSERT)"**
* **สิ่งที่ได้เรียนรู้**:
  * เข้าใจกลยุทธ์การแทรกข้อมูลลงในส่วนที่เรียงลำดับไว้แล้ว
  * สังเกตว่าในกรณี Best-case ข้อมูลที่เกือบจะเรียงอยู่แล้วจะทำงานเร็วมากในระดับ $O(n)$
  * เข้าใจหลักการของ Online Algorithm ที่สามารถรับข้อมูลเพิ่มและจัดเรียงได้ทันที

## 🕹️ โหมดการเล่น (Game Modes)
1. **แคมเปญฝึกฝน (Campaign Mode - 12 ด่าน)**:
   * ด่านที่ 1-3: Bubble Sort พื้นฐาน 4-6 ชิ้น พร้อมด่าน Worst Case
   * ด่านที่ 4-6: Selection Sort 5-8 ชิ้น
   * ด่านที่ 7-10: Insertion Sort (เริ่มต้น 4 ชิ้น, ขบวน 5 ชิ้น, Worst Case ย้อนศร, และ Best Case เกือบเรียงสมบูรณ์)
   * ด่านที่ 11-12: Master Challenge & Grand Finale
   * มีระบบประเมิน 1-3 ดาว, คะแนนรวม, คอมโบ, และเวลา
2. **ประลองความเร็วกับคอมพิวเตอร์ (AI Duel Mode)**:
   * เลือกจับคู่อัลกอริทึมได้อิสระ ทั้งฝั่งผู้เล่นและ AI Bot (Bubble, Selection, Insertion)
   * แข่งขันบนชุดตัวเลขเดียวกันเพื่อเปรียบเทียบประสิทธิภาพและความเร็ว
3. **สนามทดลองอิสระ (Sandbox Mode)**:
   * เลือกอัลกอริทึมได้ครบทั้ง 3 แบบ (Bubble, Selection, Insertion)
   * ปรับขนาดข้อมูลได้ (4, 6, 8, 10 ชิ้น) พร้อมปุ่มสุ่มชุดใหม่

| :--- | :--- |

## 📊 ตารางเปรียบเทียบทางทฤษฎี (Algorithm Comparison)

| คุณสมบัติ | Bubble Sort (แบบมี Flag) | Selection Sort | Insertion Sort |
| :--- | :---: | :---: | :---: |
| **Best Case Time** | $O(n)$ | $O(n^2)$ | $O(n)$ |
| **Average Case Time** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ |
| **Worst Case Time** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ |
| **Space Complexity** | $O(1)$ | $O(1)$ | $O(1)$ |
| **จำนวนครั้งในการสลับ (Swaps)** | มาก (สูงสุด $\frac{n(n-1)}{2}$) | น้อยมาก (ไม่เกิน $n-1$) | ปานกลาง (Shift ข้อมูล) |
| **ความเสถียร (Stability)** | Stable (คงที่) | Unstable (โดยทั่วไป) | Stable (คงที่) |
| **เหมาะกับสถานการณ์ใด** | ข้อมูลขนาดเล็ก หรือเกือบเรียงอยู่แล้ว | ลดจำนวนครั้งในการเขียนข้อมูล (Flash/EEPROM) | ข้อมูลที่เกือบเรียงอยู่แล้ว หรือรับข้อมูลแบบ Real-time |
