## 💡 กลไกการเรียนรู้อัลกอริทึมในเกม

### 1. 🫧 Bubble Sort (การเรียงลำดับแบบฟองสบู่)
* **กลไกในเกม**:
  * เกมจะชี้คู่ข้อมูลที่อยู่ติดกัน `[j]` และ `[j+1]`
  * ผู้เล่นต้องสังเกตค่า:
    * หากตัวซ้ายมากกว่าตัวขวา ให้กด **"สลับตำแหน่ง (SWAP)"**
    * หากตัวซ้ายน้อยกว่าหรือเท่ากับตัวขวา ให้กด **"ข้าม / คงเดิม (KEEP)"**
  * เมื่อวิ่งตรวจจนสุดรอบ ค่าที่มากที่สุดจะถูก "ดัน" ไปอยู่ทางขวาสุด และตำแหน่งนั้นจะถูกล็อค (Locked/Sorted ✨)
* **สิ่งที่ได้เรียนรู้**:
  * เข้าใจการทำงานแบบ Pairwise Comparison
  * สังเกตว่าในกรณี Worst-case จะต้องสลับบ่อยมาก ($O(n^2)$)
  * สังเกต Best-case ที่ข้อมูลเรียงอยู่แล้วจะผ่านได้ในรอบเดียว ($O(n)$)

### 2. 🎯 Selection Sort (การเรียงลำดับแบบเลือก)
* **กลไกในเกม**:
  * เกมจะกำหนดตำแหน่งเป้าหมาย `[i]` ทางด้านซ้าย
  * ผู้เล่นต้องสแกนดูส่วนที่ยังไม่จัดเรียง `[i .. n-1]` แล้ว **คลิกเลือกไอเทมที่มีค่าน้อยที่สุด (Minimum Value)**
  * เมื่อเลือกถูกต้อง ไอเทมนั้นจะถูกสลับมาวางที่ตำแหน่ง `[i]` แล้วล็อคทันที
* **สิ่งที่ได้เรียนรู้**:
  * เข้าใจกลยุทธ์การค้นหาค่าน้อยสุดทีละรอบ
  * สังเกตว่าจำนวนการสลับ (Swaps) มีน้อยมาก ไม่เกิน $n-1$ ครั้งเสมอ จึงประหยัดการเขียนข้อมูล เหมาะกับหน่วยความจำที่มีต้นทุนการเขียนสูง

## 🕹️ โหมดการเล่น (Game Modes)
1. **แคมเปญฝึกฝน (Campaign Mode - 8 ด่าน)**:
   * ด่านที่ 1-3: Bubble Sort พื้นฐาน 4-6 ชิ้น พร้อมด่าน Worst Case
   * ด่านที่ 4-6: Selection Sort 5-8 ชิ้น
   * ด่านที่ 7-8: Master Challenge ระดับสูง
   * มีระบบประเมิน 1-3 ดาว, คะแนนรวม, และเวลา
2. **ประลองความเร็วกับคอมพิวเตอร์ (AI Duel Mode)**:
   * ผู้เล่น (ควบคุม Bubble Sort) แข่งกับ AI Bot (ประมวลผล Selection Sort) บนชุดตัวเลขเดียวกัน
   * ดูว่าการคิดตัดสินใจของมนุษย์จะชนะความเร็วในการคำนวณของ AI หรือไม่
3. **สนามทดลองอิสระ (Sandbox Mode)**:
   * เลือกอัลกอริทึมและปรับขนาดข้อมูลได้ (4, 6, 8, 10 ชิ้น) พร้อมปุ่มสุ่มชุดใหม่

## 📊 ตารางเปรียบเทียบทางทฤษฎี (Algorithm Comparison)

| คุณสมบัติ | Bubble Sort (แบบมี Flag) | Selection Sort |
| :--- | :---: | :---: |
| **Best Case Time** | $O(n)$ | $O(n^2)$ |
| **Average Case Time** | $O(n^2)$ | $O(n^2)$ |
| **Worst Case Time** | $O(n^2)$ | $O(n^2)$ |
| **Space Complexity** | $O(1)$ | $O(1)$ |
| **จำนวนครั้งในการสลับ (Swaps)** | มาก (สูงสุด $\frac{n(n-1)}{2}$) | น้อยมาก (ไม่เกิน $n-1$) |
| **ความเสถียร (Stability)** | Stable | Unstable (โดยทั่วไป) |
| **เหมาะกับสถานการณ์ใด** | ข้อมูลขนาดเล็ก หรือเกือบเรียงอยู่แล้ว | หน่วยความจำที่ต้นทุนการเขียนสูง (เช่น Flash) |
