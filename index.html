ทำความเข้าใจ Sorting Algorithms

เปรียบเทียบขั้นตอนวิธีและหลักการทำงานของ Bubble Sort vs Selection Sort

🫧 Bubble Sort

เปรียบเทียบทีละ คู่ที่อยู่ติดกัน (Adjacent) หากตัวซ้ายมากกว่าตัวขวาจะทำการสลับที่กัน ค่าที่มากที่สุดจะค่อยๆ ลอยขึ้นไปอยู่ขวาสุดเหมือนฟองสบู่

Best Time:O(n) (มี Flag เช็ค)
Average Time:O(n²)
Worst Time:O(n²) (เรียงย้อนหลัง)
Space Complexity:O(1)
จำนวนการสลับ:มาก (ถึง n²/2)
ความเสถียร (Stable):ใช่ (Stable)

🎯 Selection Sort

สแกนค้นหา ค่าน้อยที่สุด (Minimum) ในส่วนที่ยังไม่ได้จัดเรียง แล้วนำมาสลับกับตำแหน่งแรกของรอบนั้นทีละตำแหน่งจนครบ

Best Time:O(n²)
Average Time:O(n²)
Worst Time:O(n²)
Space Complexity:O(1)
จำนวนการสลับ:น้อยมาก (ไม่เกิน n-1)
ความเสถียร (Stable):ไม่เสถียร (Unstable)

💡 ข้อแตกต่างสำคัญสำหรับการนำไปใช้จริง:

  • Bubble Sort เหมาะสำหรับชุดข้อมูลที่มีขนาดเล็กมาก หรือข้อมูลที่ เกือบจะเรียงอยู่แล้ว เพราะสามารถจบการทำงานได้ใน O(n) รอบเดียว
  • Selection Sort โดดเด่นเรื่อง จำนวนครั้งในการเขียน/สลับข้อมูล (Memory Swaps) ที่น้อยมาก จึงเหมาะกับกรณีที่ต้นทุนการ Swap มีราคาสูง เช่น Flash memory หรือ EEPROM

ประลองความเร็ว: มนุษย์ VS AI Bot

คุณจะใช้ Bubble Sort แข่งกับ AI ที่ใช้ Selection Sort บนข้อมูลชุดเดียวกัน

🤖 กฎการแข่งขัน:

  • ทั้งสองฝ่ายจะได้รับชุดตัวเลข 6 ตัวที่สุ่มเหมือนกัน
  • คุณควบคุม Bubble Sort: เลื่อนคู่ติดกันและตัดสินใจสลับหรือข้ามให้เร็วที่สุด
  • AI Bot จะประมวลผล Selection Sort อัตโนมัติทีละสเต็ปตามความเร็วที่กำหนด
  • ฝ่ายใดจัดเรียงข้อมูลเสร็จสมบูรณ์ก่อนจะเป็นผู้ชนะ!
