ทำความเข้าใจ Sorting Algorithms

เปรียบเทียบขั้นตอนวิธีและหลักการทำงานของ Bubble Sort, Selection Sort และ Insertion Sort

🫧 Bubble Sort

เปรียบเทียบทีละ คู่ที่อยู่ติดกัน (Adjacent) หากตัวซ้ายมากกว่าตัวขวาจะทำการสลับที่กัน ค่าที่มากที่สุดจะค่อยๆ ลอยขึ้นไปอยู่ขวาสุดเหมือนฟองสบู่

Best Time:O(n) (มี Flag เช็ค)
Average Time:O(n²)
Worst Time:O(n²) (เรียงย้อนหลัง)
Space Complexity:O(1)
จำนวนการสลับ:มาก (ถึง n²/2)
ความเสถียร (Stable):ใช่ (Stable)

🎯 Selection Sort

สแกนค้นหา ค่าน้อยที่สุด (Minimum) ในส่วนที่ยังไม่ได้จัดเรียง แล้วนำมาสลับกับตำแหน่งแรกของรอบนั้นทีละตำแหน่งจนครบ

Best Time:O(n²)
Average Time:O(n²)
Worst Time:O(n²)
Space Complexity:O(1)
จำนวนการสลับ:น้อยมาก (ไม่เกิน n-1)
ความเสถียร (Stable):ไม่เสถียร (Unstable)

📥 Insertion Sort

หยิบข้อมูลทีละตัวจากส่วนที่ยังไม่เรียง แล้วนำมา แทรก (Insert) ในตำแหน่งที่ถูกต้องของส่วนที่เรียงแล้วทางซ้ายมือ เหมือนการหยิบไพ่มาจัดในมือ

Best Time:O(n) (ข้อมูลเรียงอยู่แล้ว)
Average Time:O(n²)
Worst Time:O(n²) (เรียงย้อนหลัง)
Space Complexity:O(1)
จำนวนการสลับ:ปานกลาง (Shift ข้อมูล)
ความเสถียร (Stable):ใช่ (Stable)

💡 ข้อแตกต่างสำคัญสำหรับการนำไปใช้จริง:

  • Bubble Sort: เหมาะสำหรับชุดข้อมูลขนาดเล็กมาก หรือข้อมูลที่เกือบเรียงอยู่แล้ว มีกลไกเข้าใจง่ายที่สุด
  • Selection Sort: โดดเด่นเรื่อง จำนวนครั้งในการเขียน/สลับข้อมูล (Memory Swaps) ที่น้อยมาก (ไม่เกิน n-1 ครั้ง) จึงเหมาะกับ Flash memory หรือ EEPROM ที่ต้นทุนการเขียนสูง
  • Insertion Sort: รวดเร็วที่สุดสำหรับข้อมูลที่เกือบเรียงสมบูรณ์ (Nearly Sorted) ใช้เวลาเพียง O(n) และเหมาะกับการรับข้อมูลเพิ่มเข้ามาทีละตัวอย่างต่อเนื่อง (Online Algorithm)
